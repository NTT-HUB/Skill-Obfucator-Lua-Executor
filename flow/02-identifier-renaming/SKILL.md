# Skill: Identifier Renaming

## Goal

Rename local/parameter/upvalue mà không phá dynamic references.

## SOURCE

```lua
local mob = getmob(name)

local function attackTarget(target)
    return attack(target)
end

return attackTarget(mob)
```

## TARGET SHAPE

```lua
local kQ7 = getmob(J2)

local function f9x(P3)
    return qN(P3)
end

return f9x(kQ7)
```

## Must distinguish

- locals
- parameters
- upvalues
- globals
- Roblox APIs
- reflective names generated by strings

## Dangerous SOURCE

```lua
loadstring("name1=" .. #items)()
for i = 1, name1 do
    ...
end
```

Nếu rename `name1` thành `Qx9` thì generated assignment string cũng phải đổi đúng context.

## BAD SHAPE

Rename mọi spelling `name1` trong cả file hoặc protect toàn bộ spelling khỏi rename.

Cả hai đều dễ gây leak hoặc bug.

## Safety Gate

Không rename khi chưa biết identifier đó có được dùng qua:

- `loadstring`
- `getfenv`
- `_ENV`
- `_G`
- generated source strings
